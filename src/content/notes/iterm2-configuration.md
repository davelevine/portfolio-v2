# iTerm2 Configuration

This page will exist as a record of the customization done to iTerm2.

### Theme Customization

* **Theme**: [Dracula](https://draculatheme.com/iterm)
* **Shell**: [Oh-My-Zsh](https://github.com/robbyrussell/oh-my-zsh/)
* **Shell Theme**: [Dracula Zsh](https://draculatheme.com/zsh)

### iTerm2 Customization

#### Appearance

* **General**
  * **Theme**: Compact
  * **Tab bar location**: Bottom
  * **Status bar location**: Bottom
* **Windows**
  * Show window number in title bar
  * Hide scrollbars
  * Show line under title bar when the tab bar is not visible
* **Tabs**
  * Default configuration
* **Panes**
  * Default configuration
* **Dimming**
  * Everything unchecked

#### Profiles

* **General**
  * **Profile Name:** Dracula
* **Colors**
  * **Color Presets:** Dracula
* **Text**
  * **Cursor:** Underline
  * **Font**: Hack Regular 12
* **Window**
  * **Style**: No Title Bar
* **Terminal**
  * Default configuration
* **Session**
  * **After a session ends**: Close
  * **Prompt before closing?:** Never
* **Keys**
  * Default Configuration
* **Advanced**
  * Default Configuration

#### Keys

* **Key Bindings**
  * Added the following two key bindings:
    * Command+H - Split Horizontally with "Dracula" Profile
    * Command+V - Split Vertically with "Dracula" Profile

All additional tabs and settings are left as the defaults.
